WHAT CHANGED
------------------------------------------------------------------
1. Ticker: the "Clear for Today" button is removed from the alert
   strip (all pages — one strip builder), and the now-dead
   action='clear' branch in the alert-ack post handler is removed
   with it. Snooze is the strip's only defer control. (Item 1;
   Jason never asked for the button.)
2. Print menus: the three-choice menu now renders fully on-screen —
   a max-height cap with internal scroll, and a flip-up rule: when a
   Print button sits low on the page, PRINTMENU_JS adds an .up class
   on open and the menu opens upward instead of below the crease.
   One builder, so every print menu in the app is covered. (Item 2.)
3. Invoice cluster, screen behavior rebuilt to match the simpler
   forms (the printed invoice did not change except item 4):
   a. Landing: the Invoices place lands ON an invoice — /money and
      /money?tab=invoice redirect to the most recent invoice
      (invoice_date, then number), or to the blank invoice editor
      when none exist. The AR picture (Open balance / Overdue / Open
      invoices + New Invoice button) moved to the top of the
      invoices register page; the register's echo H1 is gone.
   b. Door grammar, one rule app-wide: tabs are PLACES; creating is
      an ACTION. The Billing row is now Invoices / Payments /
      Credit Memos / Cash in both tab builders. The Quotes row is
      Quotes / Change orders (the "New quote" tab is gone — the
      Quotes place lands on the blank quote form, as before). New
      Invoice is a button: on the invoice view page (beside Edit and
      the Print menu), in the editor when editing a saved invoice,
      and on the register picture. The pay form's empty-state button
      now goes straight to /invoice/new.
   c. Print buttons: exactly one Print per invoice surface, opening
      the standard three-choice menu. The print sheets' action bar
      (every document, via _doc_actions) no longer carries a
      standalone PRINT button and a standalone Print to Location
      button — it carries the same single Print menu + Back. The
      mixed report's standalone window.print button is now the
      standard page menu. Census in PHASEN-REPORT.md.
   d. Add Item: the invoice editor already added one blank .iline
      row per click — it still does. The paper-mimic signature
      preview block is removed from the screen form (the printed
      invoice keeps its own block). "Add from ready work" now
      renders closed (a one-line disclosure) instead of an open
      panel under the form; its contents and posts are unchanged.
      The invoice view page's "Add a Line" stacked mini-form is now
      one universal .iline row, same field names, same post route.
